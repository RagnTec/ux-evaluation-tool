# 04 技术架构与本地优先设计

[English](./04_technical_architecture.md) | **简体中文**

---

## 1. 架构设计原则

**UX Evaluation Tool** 采用**纯前端、本地优先（Local-First）**的架构体系。

整体架构遵循以下五项核心设计原则：
1. **100% 客户端运行**：所有图像渲染、空间标注、色彩采样及人因评估逻辑均严格在用户本地浏览器内执行。
2. **确定性数学计算**：核心评估算法（人眼视角三角函数推导、双轴物理毫米校准、WCAG 相对亮度对比度公式）均为纯数学函数，零外部 API 依赖。
3. **本地优先与数据隐私**：用户的设计截图、标注坐标及项目配置完整持久化在浏览器的本地 IndexedDB 中，绝不向任何云端服务器发送数据。
4. **分层清晰解耦**：空间证据采集、数学规则校验、多语言呈现格式化与项目本地存储各层职责明确、单向流动。
5. **零依赖报告便携性**：导出的 HTML 报告为自包含单文件，将 Canvas 证据截图与缩略图直接内嵌为 Base64 Data URL，支持在任意现代浏览器中离线查看。

---

## 2. 技术栈选型

- **核心前端框架**：React 18
- **开发语言**：TypeScript（严格类型模式）
- **构建工具**：Vite
- **画布渲染**：HTML5 Canvas 2D Context（用于像素级空间标注框绘制、手柄拖拽及精准取色）
- **本地持久化**：浏览器 IndexedDB（数据库名：`ux_evaluation_tool_db`）
- **哈希比对**：Web Cryptography API（`crypto.subtle.digest("SHA-256", ...)`）
- **国际化方案**：轻量级自定义运行时 Hook（`useI18n`），搭配类型安全的双语字典（`en`、`zh-CN`）

## 4. 核心模块详细说明

### 4.1 UI 与交互画布层 (`src/App.tsx`, `src/components/`)
- **Canvas 标注层**：在原始设计图上方叠加 Canvas 2D 绘制层，支持绘制矩形可视边界、拖拽缩放控制手柄、独立微调触控热区及展示测量指标。
- **色彩采样器**：利用 Canvas 2D 像素读取接口（`getImageData`）实时采样前景色与背景色 RGB 数值。
- **元素检查抽屉面板（Inspector）**：实时响应当前选中元素，多模块展示像素尺寸、逻辑尺寸、物理毫米、视角弧分及具体行动建议。

### 4.2 几何校准与坐标归一化 (`src/utils/logicalMapping.ts`, `src/utils/capabilityResolver.ts`)
- **归一化坐标存储**：所有空间标注均以相对原始图像宽高的 $[0, 1]$ 比例存储，确保在不同缩放和视口下几何位置严格一致。
- **双轴物理校准**：结合屏幕对角线（英寸）与物理分辨率，计算水平和垂直毫米/像素比例（`mmPerPixelX`, `mmPerPixelY`），并执行 2% 宽高比一致性约束。
- **设计逻辑单位映射**：根据设备预设或自定义参考宽度，建立像素到逻辑单位（pt / dp / CSS px）的精确缩放转换。

### 4.3 确定性规则评估引擎 (`src/humanFactors/`, `src/utils/`)
- **人因计算核心 (`src/humanFactors/`)**：纯函数计算视角弧分（$\theta = 2 \arctan(h / 2D)$），维护多参考包络（Reference Envelope）。
- **色彩对比度评估 (`src/utils/contrastEvaluation.ts`)**：严格实现 WCAG 2.2 相对亮度公式（$L = 0.2126 R + 0.7152 G + 0.0722 B$）。
- **触控人机工效 (`src/utils/interactionGeometry.ts`)**：计算相邻元素间隙距离，自动检测并告警热区重叠冲突。
- **文字排版评估 (`src/utils/textSizeEvaluation.ts`)**：校验平台字号规范，从单行文本高度或字符测量高度推导估算字号。
- **规则比对聚合 (`src/utils/ruleTrace.ts`)**：构建覆盖已开放 L1–L3 评估路径及 L4 领域适配检测的结构化 `RuleComparisonTrace` 比对链。

### 4.4 呈现与国际化 (`src/utils/elementPresentation.ts`, `src/i18n/`)
- **`buildElementPresentationModel`**：将底层的 `DesignElement` 证据与评估上下文转化为易读、格式化的呈现对象。
- **运行时双语切换**：提供中英文双语字典，支持用户在界面顶栏随时无刷新切换语言。

### 4.5 本地持久化与项目库 (`src/types/project.ts`, `src/App.tsx`)
- **IndexedDB 数据库**：自动将 `WorkspaceState` 快照序列化保存至本地对象仓库，跨浏览器会话完整保留图片 Blob、校准参数及标注数据。
- **SHA-256 去重与关联**：用户上传图片时计算其二进制哈希，自动识别同图历史项目。

### 4.6 单文件报告导出 (`src/utils/reportGenerator.ts`)
- **自包含 HTML 报告**：生成包含完整内联 CSS 样式与 Base64 Canvas 截图快照的独立单文件 HTML，无需连接外部网络即可离线分享与复盘。

### 4.7 隔离的历史演示模块 (`src/services/analysisService.ts`)
- **演示路径**：封装早期的静态模拟标注，仅供 `showDemoResults` 勾选演示使用，完全独立于真实手动空间证据流之外。

## 5. 数据隐私与安全架构

得益于完全本地化的运行架构：
- **零外发网络请求**：用户的设计草图、界面截屏、项目名称及标注数据绝不离开客户端设备。
- **无第三方埋点与追踪**：应用内无任何追踪脚本、第三方 Cookie 或远程数据收集接口。
- **完全离线可用**：在通过静态托管（如 GitHub Pages）加载完毕后，即使断开网络连接，全部功能均可正常离线运行。
