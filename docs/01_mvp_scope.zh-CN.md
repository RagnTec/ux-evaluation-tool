# 01 公开 v0.1 功能范围与能力矩阵

[English](./01_mvp_scope.md) | **简体中文**

---

## 1. 范围概述

本文档明确了 UX Evaluation Tool **公开 v0.1 开源预览版（Open Source Preview）** 的功能范围、输入输出规范及能力边界。

v0.1 的核心目标是提供一个健壮、**本地优先的浏览器端工作台**，使用户能够基于空间证据和确定性人因公式，对界面设计图进行可解释的 Human Factors 与 UX 风险评估。

---

## 2. 现已实现的评估工作流

v0.1 版本已实现完全在浏览器本地闭环运行的端到端评估生命周期：

```
[ 上传设计图 / 界面截图 ]
        │
        ▼
[ 配置显示环境与参数 ] ─── (屏幕尺寸、物理分辨率、观看距离、目标平台)
        │
        ▼
[ 交互式空间证据标注 ] ─── (在 Canvas 上圈选元素、独立调整触控热区)
        │
        ▼
[ 检查面板与测量取色 ] ─── (取色器采样前背景色、测量代表字符高度)
        │
        ▼
[ 确定性多层规则评估 ] ─── (系统自动匹配适用规则，4 级精度模型)
        │
        ├──► [ 站内评估报告预览 (Modal Preview) ]
        ├──► [ 自包含单文件 HTML 证据报告导出 ]
        └──► [ 本地项目库 / IndexedDB 自动保存与切换 ]
```

---

## 3. 纳入范围的输入规范

| 输入类别 | 支持格式与参数形式 | 核心用途 |
| :--- | :--- | :--- |
| **设计图 / 界面截图** | PNG、JPEG、WebP（拖拽或本地文件选择） | 空间评估的基础视觉素材 |
| **屏幕硬件参数** | 常见对角线预设（如 6.1″、6.7″、11″、13.3″、15.6″、27″）或自定义尺寸 + 分辨率预设（如 2556×1179、1920×1080、4K）或自定义分辨率 | 计算双轴毫米/像素比例（`mm/px`）及显示密度（PPI） |
| **观看距离** | 自由文本与单位解析（如 `500 mm`、`50 cm`、`0.7 m`、`24 in`） | 人因工程视距视角计算基准（$\theta = 2 \arctan(h / 2D)$） |
| **目标平台** | `iOS`（Apple pt）、`Android`（Material dp/sp）、`Web`（CSS px）、`自定义` | 确定对应的平台交互与排版规范 |
| **设计基准** | 具体设备预设（如 iPhone 15 Pro、Pixel 8）、自定义设计稿基准宽度或未指定 | 将图像物理像素转换为逻辑设计坐标系 |
| **截图模式** | `完整屏幕 / 界面 (full_screen)` 或 `局部截图 (cropped)`（`等比贴合` / `缩放未知`） | 调整坐标换算逻辑及屏幕面积占比解释方式 |
| **空间元素** | 在 Canvas 画布上矩形框选的目标元素 | 定义待评估的目标视觉范围（文字、图标、按钮等） |
| **触控区域** | 独立于可视边界的可调触控热区矩形 | 评估独立的肢体运动触控尺寸及相邻热区间距 |
| **代表字符测量** | 单个代表性文字字符的渲染包围盒 | 解锁字符级别的排版垂直视角精确计算 |
| **色彩采样** | Canvas 2D 取色器采样前景色与背景色 | 计算 WCAG 相对亮度对比度比值 |

## 4. 现已实现的评估能力

### 4.1 可视尺寸与面积指标
- 计算像素尺寸（$W \times H$）、包围盒面积及最短边长度。
- 计算元素在当前截图或标称屏幕面积中的占比（Area Share）。

### 4.2 物理几何与硬件校准
- 推导物理毫米（$mm$）尺寸，并进行双轴宽高比一致性校验（2% 容差限制）。
- 在截图比例与屏幕分辨率不一致时，自动标记物理尺寸估算或不可用状态。

### 4.3 人因工程视角计算
- 计算视角弧度、度数（$^\circ$）与弧分（$'$）。
- **代表字符垂直视角**：基于通用人因工效基准评估文字可读性（基本参考 $\ge 16'$，推荐参考 $\ge 20'$）。
- **图形细节垂直视角**：基于人因基准评估图标/符号识别性（基本参考 $\ge 16'$，推荐参考 $\ge 22'$）。

### 4.4 平台与物理触控人机工效
- **Apple HIG 触控目标**：校验 iOS 交互目标是否达到 $44 \times 44\text{ pt}$。
- **Android Material 触控目标**：校验 Android 交互目标是否达到 $48 \times 48\text{ dp}$。
- **Web 触控目标**：校验 Web 交互目标是否达到 WCAG 2.2 SC 2.5.8（$24 \times 24\text{ CSS px}$）。
- **通用手持直接触控物理参考**：校验交互目标是否达到人体工效学推荐基准（$\ge 9.0\text{ mm}$ 直接触控边长）。
- **触控间距与重叠检测**：自动计算与相邻最近热区的间隙距离，并标记热区重叠冲突。

### 4.5 文字尺寸与排版可读性
- **已确认设计源字号**：直接校验设计源真实字号与平台排版梯度的匹配情况。
- **截图估算字号（启发式）**：在具备设计基准时，从单行文本高度或字符测量高度推导估算字号。

### 4.6 色彩对比度与无障碍
- 校验 WCAG 2.2 SC 1.4.3 文本对比度（普通文本 4.5:1，大文本 3.0:1）。
- 校验 WCAG 2.2 SC 1.4.11 非文本对比度（界面组件与图形对象 3.0:1）。
- 结合字号与字重自动判定 WCAG 文本尺寸分类（Normal vs Large）。

### 4.7 4 级评估精度模型
自动应用当前证据支持的最高精度等级，支持单个元素内混合精度评估：
1. **截图事实（Screenshot Fact）**：像素边界、面积占比、真实色彩对比度。
2. **硬件参数估算（Hardware Assumed）**：屏幕校准后的物理毫米尺寸。
3. **设计基准校验（Design Mapped）**：基于 pt / dp / CSS px 的平台官方规范比对。
4. **源数据确认（Source Confirmed）**：经人工或设计源确认的字号与热区参数。

### 4.8 本地持久化与项目库管理
- **本地 IndexedDB 存储**：自动保存工作区快照、标注元素、显示参数及图片 Blob。
- **同图 SHA-256 哈希比对**：重新上传同名或同图时自动关联已有项目。
- **项目库列表**：支持查看本地保存的项目卡片、缩略图、修改时间及一键切换。

### 4.9 报告与呈现
- **站内报告预览**：弹窗展示覆盖范围（Covered vs Pending）、活跃标准引用及问题摘要。
- **自包含 HTML 报告导出**：导出零依赖单文件 HTML，内嵌 Canvas 标注截图与完整判定链。
- **双语界面**：提供完整的中英文界面运行时一键切换。

## 5. 条件性能力与架构预留

### 条件性能力（根据输入证据动态激活）
- **平台官方规范规则（L2）**：必须提供设计尺寸基准（pt/dp/CSS px 换算比例）。未提供时产生 `needs_info` 待补充提示，而物理尺寸与对比度规则继续正常运行。
- **人因视角计算（L3）**：必须提供有效观看距离及屏幕硬件参数。
- **物理触控目标规则**：必须提供屏幕硬件校准参数。

### 架构预留能力（暂未在公开 UI 开放）
- **L5 自定义规则导入**：数据模型中包含枚举与结构定义，但 v0.1 UI 暂未提供自定义规则编辑与上传界面。
- **座舱专项与驾驶状态评估**：车载领域提供领域适用性控制，但选择车载领域并不自动等同于驾驶员角色、行车动态或时间紧迫任务；车载专项基准需结合适用的结构化上下文，当前 Public UI 尚未开放全部座舱角色与行车状态输入。

### 隔离的演示模式（Demo Mock）
- **历史演示分析（`showDemoResults`）**：提供可选勾选框以展示预置的演示标注数据。此路径与用户手动创建的真实 `DesignElement` 空间证据完全隔离，不影响正式报告导出。

## 6. v0.1 明确的非目标（Non-Goals）

1. **不做计算机视觉（CV）自动识别**：不依赖算法自动检测按钮或文本框。
2. **不做 OCR 文本提取**：不自动识别字体名称、字重或文字内容。
3. **不做云端后端与服务端数据库**：零服务器依赖，无需用户注册，无云端同步。
4. **第一阶段不做 Figma 插件**：v0.1 纯粹作为独立浏览器 Web 应用运行。
5. **不做强制性法律/法规认证**：所有输出均为设计前期的决策支持参考。
