# 01 MVP 范围

## MVP Goal

第一阶段 MVP 用本地 H5 原型验证“上传设计图 -> 输入设备与场景参数 -> 选择目标用户与规则集 -> 输出图上风险标注和依据解释”的完整闭环。当前分析结果为 mock analysis，不代表真实 AI 自动识别。

## Priority Scenarios

- 移动端 UI。
- 车机中控 UI。
- 家电 / IoT 屏幕 UI。

## In Scope: Inputs

1. 上传设计图。
2. 输入设备与场景参数。
3. 选择目标用户与规则集。

## In Scope: Outputs

1. 图上标注。
2. 问题列表。
3. 风险等级。
4. 优化建议。
5. 依据来源。

## In Scope: Evaluation Types

1. 触控目标尺寸。
2. 目标间距 / 误触风险。
3. 颜色对比。
4. 信息层级。
5. 文字可读性。
6. 认知负荷初步风险。

## Out of Scope

1. 真实眼动预测。
2. 真实 AI 自动识别。
3. 复杂服务端规则库。
4. 完整多国家标准合规。
5. 企业协作流。
6. 评分商业化看板。
7. 第一阶段 Figma 插件化。
8. 账号系统与多人协作。
9. 持久化存储。

## Acceptance Criteria

- 用户能在本地运行并完成一次完整评估演示流程。
- 页面能展示至少 3 条模拟标注。
- 标注数据结构能表达规则层级、推理类型、依据来源、置信度和冲突状态。
- 文档明确当前 MVP 是 mock analysis，而不是真实 AI 或完整规则引擎。
