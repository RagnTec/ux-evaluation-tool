# 00 产品定义

[English](./00_product_definition.md) | **简体中文**

---

## 1. 产品名称与概述

**UX Evaluation Tool** 是一个开源、本地优先（Local-first）、基于浏览器运行的评估工具，专为人因工程（Human Factors）专家、UX 研究员、交互/视觉设计师以及产品工程团队设计。

它专注于在**设计图与界面截图级别**，针对多层人因工程基准、物理显示与交互测量、平台规范及无障碍标准，对用户界面与屏幕方案进行结构化风险评估与决策支持。

---

## 2. 核心解决的问题

在早期设计评审、设计交付以及开发前评估阶段，团队普遍面临以下痛点：
- **纯视觉评审脱离物理人机工效**：视觉稿在设计师的高清显示器上看起来比例协调，但在手持小屏上实际触控尺寸可能严重偏小，或在远距离车载视距下无法清晰识读。
- **传统可用性测试介入节点偏晚**：可用性测试通常需要可交互的原型或实际工程代码，当在测试中发现触控偏小或文字识别困难等基础人因缺陷时，方案返工成本极高。
- **常规无障碍工具依赖代码与 DOM 结构**：现存 Web 审计工具普遍要求运行态 HTML/DOM 结构，无法直接对静态设计图、车机中控截屏或嵌入式硬件界面效果图进行前期校验。
- **专业人因工具偏重且门槛高**：传统人因工效分析软件往往依赖复杂的 3D CAD 建模或光学实验室设备，难以满足普通数字化产品团队在日常敏捷设计中的轻量化评估需求。

UX Evaluation Tool 填补了这一空白，将**确定性人因工程计算、平台交互规范及空间证据标注**直接带入浏览器端的设计图评审工作流中。

---

## 3. 产品定位

- **设计图级评估**：直接基于上传的 UI 视觉稿、屏幕导出图或界面截图工作，无需可运行代码、无需特定开发框架，亦无需绑定 Figma 插件环境。
- **人因工程与 UX 结合**：将物理显示硬件事实（屏幕对角线尺寸、物理分辨率、宽高比、观看距离）与人眼视觉感知（视角弧分）、肢体运动控制（物理触控尺寸与防误触间距）紧密结合。
- **确定性与可追溯规则模型**：在底层硬性基准（L1）、平台规范（L2）、人因理论模型（L3）以及领域适用性支持（L4）等多层结构下，生成透明、可核验的规则比对追溯链（Rule Trace）。
- **能力与证据驱动的精度分级**：根据当前可用的测量证据自动应用最高精度等级（4-Tier Precision Model），消除僵化的全局模式切换。
- **本地优先与数据隐私保护**：100% 运行于用户本地浏览器环境中，图片文件、测量数据与项目工程完全保存在本地内存及浏览器 IndexedDB 中，无任何云端数据上传或外部回传。

## 4. 明确的边界与非目标（What We Are Not）

为避免产品边界与预期发生混淆，明确声明以下非目标：
- **不是宽泛的生成式 AI UI 审查工具**：不依赖未经事实锚定的大语言模型（LLM）视觉直觉或黑盒 AI 评分。所有评估逻辑均为确定性、基于规则且可追溯至具体标准。
- **不是全自动计算机视觉（CV）或 OCR 工具**：不依靠算法猜测界面元素边界或屏幕像素密度。所有空间证据均建立在用户明确框选的空间范围及显式硬件/设计参数基准之上。
- **不是单纯的 WCAG 检查器**：虽然内置 WCAG 色彩对比度评估，但其核心是将无障碍规则作为更广泛人因与交互几何评估框架中的基础组成部分。
- **不是可用性测试平台**：不替代基于真实用户的实证可用性测试、眼动仪实验或行为数据分析平台（如 Maze、UserTesting）。
- **不是法律合规认证系统**：评估结论与导出报告仅作为**前期风险发现与设计决策支持参考**，不构成法定或强制性合规认证背书。
- **不是云端 SaaS 协作平台**：不包含用户账号注册、云端项目库同步或多端在线协同编辑流。

---

## 5. 目标用户

- **交互设计师与产品设计师**：在设计定稿或研发交付前，核验物理触控区域、按键间距防误触及排版可读性。
- **人因工程师与工效学专家**：针对车载中控、智能座舱仪表盘、工业触控屏或医疗设备界面，进行视距角度及物理尺寸基准评估。
- **用户研究员**：在启发式评估（Heuristic Evaluation）或专家走查中，收集结构化、量化的空间数据证据。
- **产品经理**：在早期方案阶段评估界面可行性、多端屏幕适配风险及无障碍基础体验。
- **智能座舱 HMI 与嵌入式设备团队**：在代码实现前针对车载屏幕、家电触控面板及 IoT 设备屏幕进行界面人因走查。

## 6. 主要输入与输出

### 主要输入
1. **设计图 / 界面截图**：UI 视觉稿或屏幕截图（支持 PNG、JPEG、WebP 格式）。
2. **屏幕硬件参数**：物理屏幕对角线尺寸（英寸）与物理分辨率（用于推导双轴毫米/像素校准）。
3. **观看距离**：用户指定的标称视距（如 `500 mm`、`50 cm`、`0.7 m`）。
4. **目标平台与设计基准**：声明的目标平台（`iOS`、`Android`、`Web`、`自定义`）及可选的设计稿基准宽度（用于 pt / dp / CSS px 换算）。
5. **空间证据标注**：用户框选的元素可视边界、可选的独立触控热区、代表字符测量框及采样的前背景色彩。

### 主要输出
1. **空间证据标注层**：交互式归一化画布标注层，呈现可视边界、触控热区及测量指标标识。
2. **结构化发现与结论**：针对单个元素的行动建议（Finding），标明严重级别、所属规则层级及判定依据。
3. **多模块元素属性检查面板（Inspector）**：详细展示像素尺寸、设计逻辑尺寸、真实物理毫米尺寸、人因视角弧分及色彩对比度。
4. **自包含视觉证据报告**：零依赖的单文件 HTML 报告，内嵌 Canvas 证据大图截图、元素局部快照卡片、实际生效标准引用及评估覆盖范围。

## 7. 核心差异化对比

| 维度 | UX Evaluation Tool | 泛 AI 界面审查工具 | 传统网页无障碍工具 | 传统可用性测试工具 |
| :--- | :--- | :--- | :--- | :--- |
| **输入依据** | 静态设计图 + 明确物理硬件环境 | 设计图 + 自由提示词（Prompt） | 运行态 HTML / DOM 结构 | 交互原型 + 真实用户测试流程 |
| **评估机制** | 确定性人因公式与分层规则追溯 | 生成式大模型黑盒视觉直觉 | DOM 属性扫描与计算对比度 | 用户任务完成度与行为指标 |
| **物理几何** | 完整双轴物理尺寸校准与弧分视角计算 | 无（仅凭像素直觉） | 无（仅支持 CSS 像素） | 实验室观察与人工测量 |
| **数据隐私** | 100% 本地优先（IndexedDB 存储，零云端回传） | 图像上传至第三方云端 AI API | 视厂商而定 | 云端录屏与测试数据上传 |
| **结果可溯** | 明确规则 ID、标准出处、计算公式与精度层级 | 主观 AI 评论意见 | 标准 SC 条款引用 | 定性用户访谈与热力图记录 |
